# 261107 COMPARA-AIFS-IFS - Dashboard de previsão AIFS x IFS — Editado em 07/11/2026 às 05:46 — Versão 1.0

Dashboard que compara, lado a lado, as previsões dos modelos do ECMWF para qualquer localidade:

- **IFS** — modelo numérico baseado em física (0,25° ou HRES 9 km)
- **AIFS Single** — modelo de inteligência artificial (0,25°)

Os dados vêm da API pública da [Open-Meteo](https://open-meteo.com/), consultada direto pelo navegador, sem chave de API.

Dados: Open-Meteo.com (CC BY 4.0), a partir dos modelos do ECMWF (CC BY 4.0). Gráficos: Chart.js 4.4.1 (MIT), embutido no `index.html`.
